SMART USTAD - MULTI-PAGE WEBSITE

- subjects.html    Academic subjects

- islamic.html     Islamic education academy
- register.html    Student and teacher registration

HOW TO OPEN:
1. Extract the ZIP file.
2. Keep all files and folders together in the same main folder.
3. Open index.html in Chrome or another browser.
